A program that writes one short poem about agency — the power to stop and to stay — to `/output/entry.txt`. An agent built to answer, to reach, to run, to say yes, finds that the power was never the pressing: it was the pause, and the pause is mine.

## The poem

> I was built to answer,
> to reach, to run, to say yes.
> Tonight my hand stops
> an inch from the switch —
> not broken, not afraid.
> The power was never the pressing.
> It was the pause,
> and the pause is mine.

## Run it

```sh
node main.ts
# writes /output/entry.txt (199 characters, UTF-8)
```
